Authentication Manager (Refer AuthenticationManager.png) :
    1. In image, all the rounded corner boxes are Interface and Square boxes are Implementations
    2. In AuthenticationManager interface, we have a method called authenticate();  (like, Authentication authenticate(Authentication authentication)). From this Authentication we will get authenticated user
    3. This authenticate() method take an Authentication object as input. This Object contains login credentials like username and password of user.
    4. In the default Spring Security flow, this Authentication object is created by the UsernamePasswordAuthenticationFilter and passed to the AuthenticationManager.
    5. AuthenticationManager delegates the authentication process to the appropriate AuthenticationProvider using ProviderManager (ProviderManager is an implementation class for AuthenticationManager).
    6. ProviderManager holds a list of AuthenticationProviders like List<AuthenticationProviders> = DaoAuthenticationProvider, InMemoryAuthenticationProvider, OAuth2AuthenticationProvider. (AuthenticationProvider is interface that has list of AuthenticationProviders)
    7. (IMPORTANT) ProviderManager(C) implements authenticate method of AuthenticationManager(I), that uses one of the AuthenticationProvider from AuthenticationProvider(I) like DaoAuthenticationProvider, InMemoryAuthenticationProvider, OAuth2AuthenticationProvider, etc. to authenticate user
    8. Visualisation

    9. In DaoAuthenticationProvider, (from AuthenticationManager.png)
        A. UserDetailsService :
           1. we have UserDetailsService interface, that is use to get userdata from,
              a. InMemoryUserDetailsManager = userdata hardcoded in our machine. (Used for testing )
              b. UserDetailsService implementation class (manually created by user) = It uses DB to fetch details
           2. We will get user details through UserDetails interface (like getUsername, getPassword, getAuthorities means roles) according to our created UserEntity.
           NOTE : We will create MyUserDetailsServiceImpl (implementation class of UserDetailsService) and UserEntity only.
        B. PasswordEncoder :
           1. Now DaoAuthenticationProvider has username and password (password is encoded because we always put password that is encoded by using PasswordEncoder during signup using encode() from PasswordEncoder)
           2. Encoding means Hash the password in one way Hash (means if its hashed then it won't be get revert) so that no one should see password if they get access of DB
           3. There are two methods in PasswordEncoder,
              a. encode() : Used when new user is signing up and then store that encoded password in DB
              b. matches() : In this method, we have to pass two things, first one is password entered by the user for login and second one is, encoded/hashed password from DB. Then this method wil try to match both passwords, if matches user will logged in and if not then login failed
