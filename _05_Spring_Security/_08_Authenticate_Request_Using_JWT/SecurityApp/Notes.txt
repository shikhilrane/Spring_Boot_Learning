Authenticate Requests using JWT :
    1. We will first create custom filter as 'JwtRequestFilter'
    2. This filter will be used to send request by logged-in user to different apis in our app (This filter checks every incoming request for a JWT token)
    3. If the request contains a valid JWT token, the user is considered authenticated.
    4. We will add our custom filter 'JwtRequestFilter' just before 'UsernamePasswordAuthenticationFilter'
    5. Because we will first check if user is logged-in or not, and if logged in then request will be sent via 'JwtRequestFilter' or if not, then we will ask user to login via 'UsernamePasswordAuthenticationFilter' (Because If the token is missing or invalid, the request will go to 'UsernamePasswordAuthenticationFilter' for login.)

Creating Filter :
    1. Create filters package
    2. Create class with name JwtRequestFilter and extend this class with OncePerRequestFilter and implement its method called doFilterInternal
    3. .getHeader() from incoming request
    4. If header from incoming request is null or doesn't startsWith "Bearer ", then send request to next filter (i.e. to UsernamePasswordAuthenticationFilter)
    5. If got header, remove first 7 characters (i.e. "Bearer ") from the token
    6. Using jwtService.getUserIdFromToken(token), get the userIdFromToken from token
    7. if, userIdFromToken exist AND no user is set in SecurityContextHolder yet
    8. if, userIdFromToken exist AND no user is set in SecurityContextHolder yet then, fetch the user details from DB using extracted userIdFromToken
    9. Create authentication object for the userById
    10. Set details for created authentication object
    11. then set authenticated user in SecurityContextHolder
    12. Pass request to next filter using .doFilter()

    Now after setting authenticated object in SecurityContextHolder, we can access data for authenticated user in PostServiceImpl till JWT is valid

    Flow according to execution of custom filter 'JwrRequestFilter'
        a. Fetch Authorization token from Header
        b. Extract UserId from token
        c. Validate this userId with DB user
        d. Add this user to SpringContextHolder
        e. chain.doFilter()
            (Next Filter)
        f. UsernamePasswordAuthenticationFilter checks authentication in the SecurityContextHolder and continues the chain
        g. DispatcherServlet
        h. Controller
        j. Get user from SpringContextHolder
