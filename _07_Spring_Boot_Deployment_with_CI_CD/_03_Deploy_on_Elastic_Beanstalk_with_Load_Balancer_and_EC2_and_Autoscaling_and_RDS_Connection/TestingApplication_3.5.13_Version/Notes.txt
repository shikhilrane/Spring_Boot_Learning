Elastic Beanstalk :
    1. It is an AWS service used to deploy and run applications
       (ye AWS ki service hai jo application ko cloud pe deploy aur run karne ke liye use hoti hai)
    2. Developers only need to upload the code
       (developer ko sirf code upload karna hota hai)
    3. AWS automatically creates and manages servers for the application
       (AWS automatically server setup aur manage kar deta hai)
    4. It automatically handles load balancing, scaling and monitoring
       (ye automatically load balancing, scaling aur monitoring handle karta hai)
    5. It supports multiple programming languages like Java, Python, Node.js, .NET etc
       (ye multiple programming languages support karta hai jaise Java, Python, Node.js, .NET)
    6. It makes application deployment easy without managing infrastructure
       (infrastructure manage kiye bina application deploy karna easy ho jata hai)
    7. It helps applications scale automatically when traffic increases
       (jab users badhte hain to application automatically scale ho jati hai)
    8. It internally uses AWS services to run the application (application run karne ke liye AWS ki multiple services use hoti hain)
       • EC2 – for running servers
               (server run karne ke liye)
       • RDS – for database
               (database ke liye)
       • S3 – for storing application files
              (application files store karne ke liye)
       • Load Balancer – for distributing traffic
                         (traffic ko distribute karne ke liye)
       • Auto Scaling – for increasing or decreasing servers automatically
                        (servers ko automatically increase ya decrease karne ke liye)
