AWS (Amazon Web Services) –
    AWS is a cloud platform that provides computing resources like servers, storage, and databases over the internet.
    1. AWS stands for Amazon Web Services.
    2. It is a cloud computing platform provided by Amazon.
    3. AWS allows users to use servers, storage, databases, and other services through the internet.
    4. Instead of buying physical servers, companies can rent resources from AWS.
    5. AWS follows a pay-as-you-go model (you pay only for what you use).

Why AWS is used -
    1. To host websites and applications
    2. To store data securely
    3. To run servers and databases
    4. To scale applications easily when traffic increases

Services in AWS :
    1. On Console Home page of AWS, there are services menu > All Services
    2. All the AWS services listed out there but, we don't need to learn all of it
    3. We should know major services that are used widely like EC2, RDS, Load Balancers, Elastic Beanstalk and codepipeline
    4. We will setup RDS (Relational Database Service) in this project

Steps setup Production Database with RDS (Relational Database Service) in AWS :
    1. We can even do this in EC2, but then we have to deal with a lot of stuff manually like connectivity, availability, snapshots, proxies, and a lot of other things that are related to DBs
    2. RDS is used to create own database servers, and we will create PostgreSQL data server (we can configure which kind of DB we want to add with simple buttons)
    3. Search RDS and go to it
    4. Choose 'Create with Full Configuration'
    5. Choose 'PostgreSQL'
    6. Choose a database creation method 'Full Configuration'
    7. Choose latest engine version
    8. DB instance identifier 'postgres-spring' (Unique name of database instance used in AWS to identify database)
    9. Master username 'root' (main admin user of db, this user will have full access of DB)
    10. Credential Management > Master Password (It will decide, how will be credentials will store and manage)
    11. Instance configuration > db.t3.micro (Selecting the hardware resources for the database instance, such as CPU power, RAM, and instance type.)
    12. Storage > keep it 20 (Storage means the amount of disk space allocated to store the database data.)
    13. Connectivity > Don’t connect to an EC2 compute resource (Connectivity defines how the database instance connects to applications and networks.)
    14. Virtual private cloud (VPC) > Default VPC (A VPC is a private network inside AWS where you can launch and manage cloud resources securely.)
    15. DB subnet group > Default
    16. Public access > Yes (but in production we keep it as NO), if, :
            Yes - Database can be accessed from the public internet (if security group allows it). (Database accessible from the internet)
            No - Database can be accessed only from resources inside the VPC like Amazon EC2. (Database accessible only within the VPC network)
    17. VPC security group (firewall) (A VPC security group is a virtual firewall that controls inbound and outbound traffic to AWS resources.)
            Create new > postgres-spring-sg
    18. Availability Zone > No Preference (An Availability Zone is a separate physical data center within an AWS region.)
    19. Additional configuration > Database options > Initial database name > postres (Initial database name is the name of the first database that AWS creates inside the RDS instance during setup.)
    20. keep else as it is and submit it
    21. It will take time to create db then go to db
    22. Connectivity & security > Security group rules > Define Inbound and Outbound Rules (Defines, How TCP IP request should connect to my DB Instance)
            Inbound Rule :
                > Edit inbound rules - Behaviour of Inbound requests can be control here > choose MyIP (It will only allow with to choose connect my IP to connect)
    23. Connect from DBeaver - Create new db > PostgreSQL > paste, Host link, DB name as postgres, username as root and password > Test Connection... > Finish
        New DB will be created there, we can edit the name of DB in DBeaver
    24. Connect code to this db
        Go to application.properties > put valid spring.datasource.url, spring.datasource.username and spring.datasource.password
        Run the application
        In log we can see that, our application is connected to "Added connection org.postgresql.jdbc.PgConnection@20820df0"
        Now when we check the DB we will have table of name "employee" (Db table as per entities)
        We can use postman to check if we can create and get employee and that will get reflected in this DB

NOTE : No one else can access to this DB as we set in inbound as MyIp and we will change that behaviour in Security group later on
