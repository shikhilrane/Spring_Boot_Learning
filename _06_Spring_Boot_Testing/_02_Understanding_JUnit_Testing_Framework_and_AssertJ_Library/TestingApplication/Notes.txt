Testing in Java :
	1. To understand testing in Java we should know JUnit and AssertJ
		JUnit = A framework used for writing and running tests in Java.
		AssertJ = A library used to write clear and readable assertions in Java tests.
	2. These two are not related to Spring, these are related to Java and use to write test in Java

JUnit 5.0 : 
	1. It is use to write, run and maintain test cases.
	2. JUnit comes in 'spring-boot-starter-test' dependency
	3. Common JUnit Annotations :
		@Test : Marks a method as test method. JUnit will execute this method when running tests.
		        We should not return anything from test method and always use void as return data type
		        We can create as many test methods
		@DisplayName : Sets a custom display name for the test class or test method. This name is used in test reports and IDEs
		@Disabled : Disables a test class or test method . Disabled tests are not executed.
        @BeforeEach : Indicates that the annotated method should be executed before each test method. These can be used to reset each test case conditions.
        @AfterEach : Indicates that the annotated method should be executed after each test method
        @BeforeAll : Indicates that the annotated method should be executed once before all test methods in the class. The method must be static. (Executed once)
        @AfterAll : Indicates that the annotated method should be executed once after all test methods in the class. The method must be static. (Executed once)
        There are many JUnit annotation, we can check it out here : https://docs.junit.org/6.0.3/api/index.html
    4. JUnit is a popular testing framework used in Java. It helps developers write test cases, run them, and check the results in a simple and standard way.

Assert :
    1. We will first use assert from JUnit and then we will use AssertJ library that provides better way of writing assertions
    2. But we can't do operations like on Strings or Arrays or can't even do chaining
    3. So for that we will use AssertJ library

AssertJ :
    1. AssertJ is not a testing framework. It is a library that works with testing frameworks like JUnit to make writing test assertions easier and more readable.
    2. It provides clear and easy-to-read assertions, which makes test code more understandable and easier to maintain.
    3. JUnit and AssertJ are both popular tools used for testing in Java, but they have different roles and features.
    4. Import, import static org.assertj.core.api.Assertions.assertThat; and start using AssertJ library
    5. we should only handle one assertThat in one test case
    6. Common AssertJ Methods
       1. Numbers:
           assertThat(5).isEqualTo(5).isNotEqualTo(10).isGreaterThan(4);
       2. String:
           assertThat("hello").startsWith("he").endsWith("lo").contains("ell");
       3. Boolean:
           assertThat(true).isTrue(); OR assertThat(false).isFalse();
       4. List/Array:
           assertThat(List.of("apple", "banana"))
                   .contains("apple")
                   .doesNotContain("orange")
                   .hasSize(2);
       5. Exceptions:
           assertThatThrownBy(() -> {
                   throw new IllegalArgumentException("Invalid argument");
               })
               .isInstanceOf(IllegalArgumentException.class)
               .hasMessage("Invalid argument")
               .hasStackTraceContaining("ExampleTest");

       More AssertJ Methods: https://assertj.github.io/doc/

JUnit and AssertJ relation :
    JUnit is a framework used to write and run tests in Java, and AssertJ is a library used with JUnit to check and verify the results of those tests.
