JaCoCo Test Report Generation :
    1. JaCoCo stands for "Java Code Coverage"
        (JaCoCo ka matlab hai Java code coverage, yani ye batata hai ki hamare tests ne kitna code cover kiya hai.)
    2. JaCoCo is a library
        (JaCoCo ek library hai jo Java projects me test coverage measure karne ke liye use hoti hai.)
    3. JaCoCo is a free Java code coverage library distributed under the Eclipse Public License. The library is often used in Java projects to measure the coverage of unit or integration tests.
        (Ye ek free Java library hai jo Eclipse Public License ke under distributed hai aur unit tests ya integration tests ki coverage measure karne ke liye use hoti hai.)
    4. Use https://www.baeldung.com/jacoco to get Jacoco maven plugin
        (JaCoCo Maven plugin ke baare me samajhne aur configuration ke liye is link ka use kar sakte hain.)
    5. Running the test using JUnit will automatically set in motion the JaCoCo agent. It will create a coverage report in binary format in the target directory target/jacoco.exec
        (Jab hum JUnit tests run karte hain tab JaCoCo agent automatically start ho jata hai aur coverage report binary format me target folder me generate hoti hai.)
    6. Benefits of JaCoCo
       • Visibility into Test Coverage
            (Ye clearly dikhata hai ki code ka kitna part tests se cover hua hai.)
       • Identify Dead Code
            (Ye aise code ko identify karne me help karta hai jo kabhi execute nahi hota.)
       • Focus on Critical Areas :
            By showing which parts of your code are not covered, JaCoCo allows you to focus your testing efforts on the most critical and potentially vulnerable areas of your application.
            (Ye batata hai ki code ka kaunsa part tests se cover nahi hua hai jisse hum un important areas par zyada focus kar sakein.)
       • Better project maintenance, compliance and standards
            (Isse project maintain karna easy ho jata hai aur testing standards follow karna bhi simple ho jata hai.)

Test report Generation by IntelliJ :
    1. Right click on src > test > java > com.shikhilrane.TestingApplication
        (Testing package par right click karte hain jahan hamare test classes present hain.)
    2. Click on "Test in 'TestApplication'" with coverage
        (Coverage ke saath tests run karte hain taaki pata chale kitna code cover hua hai.)
    3. It will show how much integration code coverage we are getting
        (Isse pata chalta hai ki hamari integration testing se kitna code cover ho raha hai.)
    4. When we click on button "Generate Coverage Report..." button then it will generate nice .html page
        (Generate Coverage Report button par click karne se ek HTML report generate hoti hai.)
    5. htmlRepost folder will get generated there in root folder, and it will contain all the test report details
        (Root folder me htmlReport naam ka folder generate hota hai jisme saari coverage report details hoti hain.)

Test report Generation by JaCoCo :
    1. Add JaCoCo plugin with latest version :
       (Pom.xml me JaCoCo Maven plugin add karte hain taaki coverage report generate ho sake.)
        <plugin>
            <groupId>org.jacoco</groupId>
            <artifactId>jacoco-maven-plugin</artifactId>
            <version>0.8.14</version>
            <executions>
                <execution>
                    <goals>
                        <goal>prepare-agent</goal>
                    </goals>
                </execution>
                <execution>
                    <id>report</id>
                    <phase>prepare-package</phase>
                    <goals>
                        <goal>report</goal>
                    </goals>
                </execution>
            </executions>
        </plugin>
    2. Maven clean and then install, so that target folder will get generated again with JaCoCo reports
        (Maven > TestingApplication > clean > install) or run "./mvn clean package" command in terminal
        (Maven clean aur install run karte hain taaki target folder dobara generate ho aur usme JaCoCo reports aa jaye.)
    3. Then newly generated "target" folder will have jacoco.exec in it and it has whole report in binary format, and that will use to generate report by using 3rd party softwares and that can read this file and create diagrams and dashboard for you
       (Target folder me jacoco.exec file generate hoti hai jo binary format me coverage data store karti hai aur ise third party tools use karke graphs aur dashboards banaye ja sakte hain.)
    4. Go to  target/site/jacoco/index.html > right click > click "reveal in finder" > open the index.html file
                                            or
       Run "target/site/jacoco/index.html" in terminal
